GSE300977 MULTI-PASS-ONLY FIRST VS INTERNAL SENSITIVITY V1

STATUS:
Post-reveal topology-composition sensitivity analysis.

PURPOSE:
Determine whether the previously observed FIRST-vs-INTERNAL spatial
differences persist after removing the inherent composition difference
that INTERNAL TMDs occur only in multi-pass proteins whereas FIRST TMDs
can occur in both single-pass and multi-pass proteins.

MULTI-PASS-ONLY UNIT:

contributing frozen target transcript has pass_class = MULTI_PASS.

If contributing target transcripts contain both SINGLE_PASS and
MULTI_PASS classifications:
topology_class = MIXED_TOPOLOGY
and the unit is excluded from the multi-pass-only analysis.

No representative transcript is chosen.

FIRST = position_class_consensus FIRST
INTERNAL = position_class_consensus INTERNAL
MIXED position class is excluded from FIRST-vs-INTERNAL comparison.
