# Input provenance and rights boundary

Sixteen processed analysis/metadata inputs are reused in place from the existing reviewer code package. INPUT_MANIFEST.tsv specifies their exact package-relative locations, sizes and SHA-256 values. One annotation-derived input is added under inputs/: GSE300977_FORMAL_GENOMIC_TMD_ANCHORS_v1.tsv (2,958,079 bytes; SHA-256 6f065fad3c851cbd6bcc07e2871d3459e1b395a684b7ec57ad19ea440f0db86f). It is the exact frozen bridge table used by the independent audit, not a newly inferred annotation. Its transcript, gene, TMD-index and coordinate identities are checked against the packaged formal anchor candidates and paired geometry table. This is processed-input identity verification, not independent raw-to-annotation reconstruction or verification of upstream annotation/model provenance.

The new genomic anchor table, existing processed data, derived outputs and protocol are not declared author-owned software by this extension. They retain applicable documented source/annotation and material terms. No new blanket permission or relicensing is asserted. The package LICENSE_SCOPE.md, MIXED_LICENSE_RECORD_SCOPE.md and existing third-party notices remain applicable and unchanged. Only the newly authored Python scripts are added to FILE_LEVEL_CODE_LICENSE_MANIFEST.tsv under the recorded author-direction MIT scope. Dependencies retain their own licenses and are not vendored here.

Original audit protocol and freeze metadata are retained as path-normalized documentary copies; the separately recorded original digests identify the historical freeze. These documentary copies do not establish a new pre-result timestamp. Executable scripts use package-relative inputs and an explicit new output directory. The original experiment, metadata-pairing and biological-coverage limitations are unchanged.
