# Falsification tests of TMD-relative ribosome profiles identify topology-associated compartmental differences

P3 NARGAB reproducibility package — v1.0.0 release candidate.

This repository contains author-owned analysis code, licensed third-party components, frozen processed inputs, figure source data and recorded analysis contracts for the manuscript by Ming Li, Kyoto University. The sole prespecified +75-nt primary was not supported. The topology-by-compartment and region-composite associations are post-reveal observational robustness results. Biological replication is not increased by gene resampling.

## Data sources

GSE106329 and GSE133111 are specificity benchmarks; GSE300977 supplies the compartment/topology analysis. GSE61012 and GSE59573 address additional specificity and perturbation questions. GSE255657 supplies the TOM22 component generalization test, without matched ER. Completed O1/O2 and TOM22 boundary records remain in supplementary_tables/Supplementary_Table_12. No new analysis was performed while preparing this release.

## Reproduction boundary

The code/ directory includes the frozen processed region inputs, deterministic seeds, pinned dependencies and a main reproduction entry point. Its documented command reproduces the region TSVs, checks selected saved statistics, and rebuilds Figures 1, 2 and 4 from frozen tables. Figure 3 is frozen artwork and is not regenerated by that command. Primary/benchmark statistics are verified as saved outputs, not recalculated by the main command. Historical upstream raw-data workflows and external extensions are not turnkey; some upstream inputs/preprocessing details are not bundled or exactly reconstructable.

Figures/ and Supplementary_Figures/ are exact copies of the final authoritative manuscript artwork. Historical plotting/presentation sources are retained in code/. The main reproduction command is a scientific-content workflow; it is not claimed to reproduce the final later typography/panel-layout edits byte-for-byte. Run it in a disposable extraction because it writes to Figures/. Current artwork hashes are recorded in PUBLIC_FILE_SHA256.tsv.

## Environment and commands

See [full instructions](code/REPRODUCE_NARGAB.md), [conda environment](code/environment-nargab.yml) and [dependency pins](code/requirements-nargab-lock.txt). Byte-identical scientific TSV reproduction was historically verified in the documented macOS arm64 Accelerate reference environment; arbitrary platforms are not asserted equivalent.

From code/:

```sh
conda env create -f environment-nargab.yml
conda activate p3-nargab-2026
python verify_nargab_outputs.py
```

The last command checks saved values without running the scientific analysis. The supported full command for a user choosing to reproduce the frozen calculations is:

```sh
python reproduce_nargab.py
```

No scientific command was executed in this public-release preparation task.
