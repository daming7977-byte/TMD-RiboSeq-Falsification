# Route A support and missingness contract v0

Frozen before any gene-wide coverage audit or TMD-centered outcome access. This contract permits only totals of uniquely assigned, in-frame accepted A-sites per complete canonical CDS for technical evaluability. No anchor-relative counts or condition effects are calculated in this task.

For each length separately (27/+14 primary, 28/+15 sensitivity), use the exact Task12 alignments and coordinate reference. Reject unmapped and multiple reported placements; require NM=0 and full-length M CIGAR. Assign mapped 5prime plus offset on plus strand or minus offset on minus strand. Require exactly one coding-strand CDS at the A-site and CDS nucleotide index divisible by3. No rounding, duplicate collapse or additional trimming. Count one accepted read once in that CDS. Complete CDS includes annotated start and terminal stop codon, as in the frozen technical model. Denominator K is annotated CDS_nt/3 including stop. No position values are retained in the support audit.

For condition c, footprint l, gene g, N(g,c,l) is total usable accepted CDS A-sites. Gene-condition is evaluable iff N>0. No minimum expression/depth cutoff beyond positive coverage; low positive depth remains eligible and may be noisy. Mean density is N/K. Zero total is technically non-evaluable, never assigned a pseudocount or zero specificity. A zero local window with positive CDS total remains a genuine zero count, not a missing observation. All eligible anchors in an evaluable gene are retained; no anchor-specific coverage filter.

PRIMARY_COMMON_SUPPORT is annotation-eligible genes with N>0 in noCHX, 100x rep1 and 100x rep2 for BOTH27 and28 nt. Requiring both experiments prevents substituting one 100x sample when the other is missing. SEVEN_DOSE_COMMON_SUPPORT requires N>0 in all eight libraries for BOTH lengths. These are two predeclared fixed intersections; the secondary cannot change its gene set by condition. Both footprint analyses use the identical support set for each estimand. Never impute, combine read lengths, pool experiments or replace a missing 100x experiment. Report annotation anchors, evaluable gene-condition anchors, primary common genes/anchors and seven-dose common genes/anchors separately. No dependence on local profile, direction or magnitude.

All eligible anchors of retained genes enter equally within gene; genes enter equally. Both 100x experiments are averaged equally at gene-statistic level, never by read depth. For condition-level descriptive profiles/summaries across all doses use the seven-dose common set. Primary endpoint reporting uses its primary common set. No condition-specific support population. Visualization, if subsequently authorized, uses only -60..+100 inclusive and the same fixed normalization, without smoothing.

If fewer than two common genes remain for an estimand, mark it TECHNICALLY_NON_EVALUABLE and do not bootstrap or issue a support verdict. Otherwise use the frozen bootstrap without depth weighting. Gene resampling is not biological replication.

This support rule is frozen now; realized membership may be computed using CDS totals only. Full aligned-file hashes must match Task12 before access. The design's final manifest fixes the observed support membership for the first authorized execution.
